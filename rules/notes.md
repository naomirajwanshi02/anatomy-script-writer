# Notes overlay, reel export and the build database

Moved out of CLAUDE.md (section 11) so it loads only for notes, subtitle, engraving, reel or MP4 work. The figure engraving rule stays in CLAUDE.md section 5.

Finished reels are made in `builds/notes/`. Read `builds/notes/README.md` before any notes, subtitle, engraving or MP4 work; it is the full guide. Do not rebuild that pipeline from scratch.

- **What it is:** each episode has a cue file `builds/notes/episodes/<NN>.mjs` and a transcript `<NN>.words.json`. `npm run notes -- <NN>` writes the notes page next to the voice page; the voice page is never edited. Episode 01 is the reference.
- **Commands:**
  - `npm run notes:transcribe -- <mp3> <out.words.json>` (whisper env in `.tools/whisper`)
  - `npm run notes:sheet -- "<page>" <sec> …` (contact sheet in `builds/notes/.check/sheet.png`; renders a copy, so it never writes a .mov into `shorts/`)
  - `npm run notes:export -- "<page>"` (writes `<question> (reel).mp4`: alpha render on `shorts/backdrops/Sepia paper.png` plus `<N>.mp3`, H.264 + AAC, 1080x1920, 30 fps)
  - `node builds/notes/autoplace.mjs <cue.mjs> --write` (moves notes and tie arrows that would fail R1-R6, before `notes:check`)
- **Every board has the engraving:** every notes page gets the `ROLLIN-रोलिन-ROLLIN-रोलिन` engraving on the board's front face. Measure the face for each board (README section 4).
- **House style:**
  - Notes in Samble (`samble/samble.otf`), #2a1d10, on olive (#4f5d24) hand-drawn arrows. Doodles are kept (bulb, squiggles, wavy underlines, boxes); water analogies get a glass of water, never a drop.
  - No printed subtitles in the reel. The plain-words takeaway (SCRIPTS.md section 3) is written below the board; chip-design reels have no real-world close.
  - The `ROLLIN-रोलिन-ROLLIN-रोलिन` engraving goes on the board's front edge in the kit label style (small, mid tone, no wood).
- **Every video:** the end card is the boxed takeaway in the centre of the subtitle area, appearing 4 s before the end, and the sign-off sequence, generated by `npm run notes:signoff`: the "1 : 0" scoreboard pun (owner, 2026-11-03): "final score" and "you" write on "you", a big "1" on "explain", "most engineers" on "most", a big "0" on "can't", in the top zone above the board, then "Follow" (y ≈ 1530, clear of both apps' bottom strip; one video for Reels and Shorts) on the spoken word, an olive arrow to the follow button and a double underline with sparks on "keep it that way"; "Follow" line-boils (noise displacement) and never grows.
- **Pen marks:** fit them on a frame at their own second, only after folds settle.
- **Overlaps are enforced:** `npm run notes:check -- "<page>"` must pass (rules R1-R8 in the README: no note over note, label, readout or part; no pen stroke through text or labels; no arrow tip on a part; at most 3 notes on screen, at least 1.5 s between new notes). `notes:export` runs it first and refuses to render while anything fails. Never work around it; fix the cue.
- **Database:** `series/reel-builds.csv` has one row per episode (stage, files, status, date). Update it whenever a stage finishes.
- My iPad annotations: words in brown-black #2a1d10, arrows, circles and underlines in olive #4f5d24, pen 3-4 px. Figures never use olive, so the two never mix up (CLAUDE.md section 3).
